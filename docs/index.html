Cursor Plan Usage

How much of your Cursor plan is gone?

Live Cursor Models and Other Models meters in your sidebar and status bar, with the same numbers at the end of the cycle. Git-aware windows show what a commit or a branch cost you.

Features

Meters first, everything else below

The top of the sidebar answers one question: how much have I used. The rest is there when you want it.

Always on

At a glance

  • Cursor Models and Other Models meters, with the projected end-of-cycle percent
  • Status bar chip: CM n% · OM n%
  • Billing cycle progress and reset time

Git-aware

What it cost you

  • Since last commit: plan % burned while the tree is dirty. Resets on each commit
  • This branch: pauses on main and restores when you return
  • Usage so far: a resettable window that survives reloads

Heads-up

Alerts that matter

  • Warns at 80% and 95% by default, once per meter per cycle
  • Optional monthly budget, warned when the projection passes it
  • Session token expiry warning 24h before it runs out

Below the meters

Dig deeper

  • 14-day usage history chart, collapsed under the meters
  • Export Usage (CSV): up to 35 days of daily peaks
  • Copy Diagnostics: versions and token status for bug reports. Never the token, emails redacted
Session deltas Smart refresh, pauses when Cursor is unfocused Adaptive polling No telemetry

Command palette

Everything runs from Ctrl/Cmd+Shift+P

Type Plan Usage to see them all.

Command What it does
Plan Usage: Focus Open the sidebar
Plan Usage: Refresh Force a usage refresh now
Plan Usage: Export Usage (CSV) Save the daily history as a CSV file
Plan Usage: Copy Diagnostics Copy a redacted report for bug reports
Plan Usage: Set Session Token Override Cursor's local token with your own JWT
Plan Usage: Clear Session Token Remove the override and use Cursor's local token again

Open source

MIT licensed and fully readable on GitHub. Audit it, fork it, or send a pull request.

Privacy

Your access token stays on your machine and is never written to disk by the extension. No telemetry. The only network call is the usage request to Cursor’s API.

Lightweight

Smart refresh pauses when Cursor is unfocused and avoids unnecessary background work.

Native to Cursor

Lives in the sidebar and status bar, using Cursor’s existing UI instead of opening another dashboard.
